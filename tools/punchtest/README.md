# UDP 打洞环境探针

用于判断两个 NAT 环境之间能否完成 UDP 打洞，与业务协议无关（frp 同款思路）。

## 部署

1. 信令服务器：放到有公网 IP 的机器（如 relay 服务器）：

   ```bash
   python3 server.py 30001
   ```

   需要放行对应 UDP 端口。

2. 两个客户端分别放到待测的 NAT 后：

   ```bash
   # 端 A（如网吧服务器，可用高位端口绑定）
   python3 client.py cafeA <信令服务器ip>:30001 42002
   # 端 B（如 IDC）
   python3 client.py idcB <信令服务器ip>:30001
   ```

## 判定

- 任一端打印 `打洞成功！观测到对端真实来源 ...`：两端之间 UDP 打洞可行；
- 两端都打印 `打洞失败`：当前 NAT 组合不支持打洞（至少一侧为对称/受限 NAT）。

注意：打洞成功只需要"提供数据方"可达（全锥/映射）；下载方无需特殊 NAT。本探针两端角色对称，任一方成功即说明该组合存在可行路径。
