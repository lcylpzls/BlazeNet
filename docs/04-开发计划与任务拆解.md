## 3. 依赖与关键路径

```text
M0 → M1 → M2 → M3 ┬→ M4 ─┐
                    └→ M5 ─┼→ M7 → M8
                    └→ M6 ─┘
```

- 关键路径：M0 → M1 → M2 → M3 → M4/M5 → M7 → M8；
- M3 是唯一被 M4/M5/M6 共同依赖的模块，建议优先保证；
- M5 与 M6 无相互依赖，可并行；
- 真实 NAT 打洞采样（M7）依赖 M5 完成，若有风险需提前。

## 4. 风险与应对

| 风险 | 应对 |
| --- | --- |
| 预估工时普遍偏乐观 | 全部人工上浮 30%~50% 后作为排期基线 |
| iroh Windows 构建问题 | M5 第一天即验证构建，失败则提前找替代方案 |
| 真实游戏差异率不达标 | M0 决定是否调参（512KiB）或引入文件级差分（二期） |
| 打洞成功率过低 | 已有降级路径（只下载）；采样后决定是否强制端口映射 |
