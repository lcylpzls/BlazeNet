# BlazeNet 管理交互设计（二期）

> 状态：草案（供人工审阅）
> 日期：2026-08-26
> 原则：制作机是"内容生产端独立操作台"；其余一切管理集中在云端 Web。

## 1. 总体信息架构

```text
┌──────────────────────────────┐      ┌──────────────────────────────────────┐
│ 制作机独立操作台（Windows）     │      │ 云端 Web 管理后台（浏览器）             │
│ · 游戏源目录/版本管理           │      │ · 工作台/仪表盘                       │
│ · 分块与制作任务                │      │ · 节点管理（IDC/网吧/中继/原始节点）    │
│ · 上传原始节点与发布审批         │      │ · 场所/分组/账号                     │
│ · 制作与上传报告/日志            │      │ · 游戏与版本管理/回滚/灰度             │
│ · 本地配置（源目录/分块参数）     │      │ · 任务管理/调度策略/限速/中继          │
└──────────────────────────────┘      │ · 监控告警/审计/系统设置               │
                                      └──────────────────────────────────────┘
```

制作机只负责"内容进入原始节点"；内容到达后的纳管、下发、更新、回滚、监控全部由云端 Web 完成。

## 2. 制作机独立操作台

### 2.1 定位与运行形态

- Windows 桌面应用（一期为 CLI，二期增加 GUI），程序目录规范沿用一期；
- 与原始节点 gRPC 直连；不依赖调度中心即可完成制作与上传；
- 单实例锁保留；制作任务落本地队列，可断点续跑。

### 2.2 页面与交互

| 页面 | 核心元素 | 交互说明 |
| --- | --- | --- |
| 工作台 | 当前任务进度、上传速率、最近报告 | 制作/上传任务实时进度条；失败可重试 |
| 游戏库 | 游戏列表、版本号、源目录、状态 | 选择源目录与上一版本目录，创建制作任务 |
| 制作任务 | 分块进度、差异统计、输出目录 | 参数：分块大小、压缩、输出目录；可取消/重跑 |
| 上传中心 | 上传队列、秒传统计、失败块列表 | 按块重传；完成后自动 commit 并提示是否发布 |
| 版本历史 | 每个游戏的历史版本、变更摘要 | 对比任意两版本差异；回滚需到云端 Web |
| 校验报告 | 文件数、块数、哈希校验结果、磁盘占用 | 报告可导出 |
| 设置 | 原始节点地址/Token、默认分块参数、输出目录 | 本地保存 |

### 2.3 关键交互状态机（制作任务）

```text
草稿 → 分块中 → 上传中 → 提交中 → 已发布 / 失败
                 ↑           │
                 └── 重试 ────┘
```

- 分块失败：保留已分块，修复源文件后增量重跑；
- 上传失败：按失败块列表重传，秒传跳过已完成块；
- 提交失败：展示缺失块与原因，补齐后重提；
- 发布动作：默认"仅提交到原始节点"，是否对全网生效由云端 Web 控制。

## 3. 云端 Web 管理后台

### 3.1 角色与权限（RBAC）

| 角色 | 权限 |
| --- | --- |
| 超级管理员 | 全部功能 + 系统设置 + 账号管理 |
| 运维 | 节点/中继/任务/限速/备份/升级 |
| 运营 | 游戏/版本/发布/灰度/回滚/任务 |
| 只读 | 查看仪表盘/节点/任务/审计 |

权限控制到接口与按钮两级；所有敏感操作写审计。

### 3.2 页面地图

```text
工作台
├─ 全局概览：节点在线数、任务进行数、带宽曲线、告警数
├─ 游戏热度榜
└─ 待办/审批

节点管理
├─ 节点列表（IDC/网吧/中继/原始节点，多 IP 地址表）
├─ 节点详情（状态、磁盘、带宽、持有块统计、任务历史）
├─ 节点分组批量操作
└─ 中继实例管理（信令/中继模式开关、会话、限流）

场所/分组/账号
├─ 场所、分组、账号多对多绑定
└─ 账号权限分配

游戏与版本
├─ 游戏列表（版本、当前生效版本、状态）
├─ 版本详情（块统计、变更、共享块）
├─ 发布/回滚/灰度
└─ 版本清理策略

任务管理
├─ 任务列表（状态机：排队→运行→完成/失败/取消）
├─ 创建任务（选择节点/场所/游戏/版本/策略）
├─ 任务详情（进度、块分配、源节点、错误）
└─ 批量重试/取消/暂停

监控告警
├─ 指标大盘（Prometheus）
├─ 告警规则与通知
└─ 节点健康评分

审计
└─ 操作日志查询（人/动作/对象/时间/详情）

系统设置
├─ 管理员账号、Token、TLS
├─ 限速与调度策略
├─ 备份/升级
└─ 全局参数
```

### 3.3 关键交互设计

#### 创建任务

1. 选择对象：单节点 / 场所 / 分组 / 全部 IDC；
2. 选择游戏与目标版本；
3. 选择策略：立即 / 低峰 / 灰度百分比；
4. 预估：节点数、目标磁盘占用、预计带宽；
5. 确认后进入任务状态机，页面实时展示每节点进度。

#### 发布/回滚

- 发布：版本已由制作机提交后，运营在"游戏-版本"页执行发布，可选择灰度比例与目标分组；
- 回滚：选择目标历史版本，系统为受影响节点批量生成 ROLLBACK 任务，页面展示预计回滚范围；
- 危险操作二次确认 + 输入原因，审计留痕。

#### 节点详情

- 顶部状态徽标（在线/离线/磁盘告警/同步中）；
- 数据面地址表（多 IP、kind=config/stun、链路健康）；
- 磁盘/带宽实时曲线；
- 已纳管游戏与版本，可一键发起更新/回滚/停用。

#### 中继管理

- 实例列表：区域、在线、模式（信令/中继）、带宽利用率、会话数；
- 切换模式：立即生效，存量会话按策略（立即断/自然结束）处理；
- 会话详情：来源、目标、速率、流量、校验结果。

### 3.4 前端技术

- React + TypeScript + Vite + Ant Design 5；
- 二期前后端分离：Nginx 托管静态资源 + 反向代理后端 API；
- 数据刷新：列表轮询 + 任务/节点实时 WebSocket 推送；
- 状态机统一由后端驱动，前端只渲染，避免双端状态漂移。

## 4. 接口与事件约定

- 所有列表接口支持分页、过滤、排序；
- 任务/节点状态变更通过 WebSocket 推送事件；
- 危险操作统一 `POST /api/.../actions` 语义 + 幂等键；
- 制作机与云端共享游戏/版本数据模型（游戏 ID、版本号、清单哈希）。
